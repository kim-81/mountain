## 외부 준비 사항

- **Railway 무료 체험 진행 승인:** 사용자가 계정 가입·약관 확인을 직접 준비. 유료 결제·전환은 별도 동의. 아직 실제 서버를 만들거나 배포하지 않았습니다.
- **iPhone만 보유, Mac 없음:** Mac/Xcode 빌드 환경 확보가 필요합니다. 접근 가능한 Mac 또는 별도의 빌드 환경을 결정해야 하며 비용·계정 사용은 별도 동의입니다.
- 날씨·통제·시설 자료는 제공처의 키·사용 조건을 확인해야 합니다. 연결되지 않은 자료를 실시간 정보라고 표시하지 않습니다.
- 실제 GPS 피드백은 사용자의 다음 등산 때 반영합니다. GPS 검증을 기다리며 다른 개발을 멈추지 않습니다.

마감 위험이 큰 항목은 공개 서버 개통, iOS 빌드 환경, 실시간 자료 사용 권한, 현장 GPS 확인입니다. 이 네 항목은 코드를 작성한 것만으로 완료 처리하지 않습니다.
