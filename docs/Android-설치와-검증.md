# 산길따라 Android 테스트 설치 · 0.8.6

2026-11-20 기준. APK 서명과 포함 파일을 확인했습니다. Android 15 가상 기기에서 설치, 첫 화면, 모의 GPS 기록과 복구, 백그라운드 이탈 알림을 확인했습니다. 실제 휴대폰 검증 결과는 아직 없습니다.

이전 테스트 버전에서 업데이트하기 전에 진행 중인 산행을 종료해 저장하고, 필요한 기록은 JSON으로 내보내세요. 개발용 서명과 앱 ID가 같은 경우 기존 앱 위에 새 APK를 설치할 수 있습니다. 실제 휴대폰의 업데이트와 자료 보존은 확인 전입니다.

Android 15 가상 기기에서 v0.8.3 위에 v0.8.4를 설치한 뒤, 이전 버전 저장소에 넣은 시험 산행 기록과 아차산 즐겨찾기가 새 버전의 ‘나의 산행’ 화면에 표시됐습니다.

## 설치

1. PC의 [v0.8.6 APK](../outputs/sangil-ttara-0.8.6-debug.apk)만 USB 등으로 본인 Android 휴대폰에 옮깁니다. Android 8 이상이 필요합니다.
2. 휴대폰의 파일 앱에서 APK를 열어 설치합니다. 해당 파일 앱의 ‘출처를 알 수 없는 앱 설치’ 허용이 필요할 수 있습니다. 이 프로젝트에서 받은 파일인지 확인하고 시스템 안내를 따르세요. 설치 후 해당 허용은 다시 끌 수 있습니다.
3. ‘산길따라’를 실행합니다. 이번 APK는 개발용 서명이며 스토어 정식 출시본은 아닙니다.
4. 기존 앱과 서명이 달라 설치가 거부되면 기존 앱을 바로 삭제하지 마세요. 앱 삭제 시 기기 저장 기록도 지워집니다. 오류 화면과 기존 설치 경로를 먼저 확인하세요.

## 확인 순서

안전한 평지에서 먼저 확인하고 결과를 남기세요. 현재 경로 자료는 현장 검증 전입니다.

| 순서 | 확인할 동작 | 통과 기준 | 현재 결과 |
|---|---|---|---|
| 1 | 첫 실행·검색·산 상세 | 서울 8개 산을 찾고 상세가 열림 | 휴대폰 미검증 |
| 2 | 북한산·아차산·관악산 지도 | 배경과 OSM 기본 경로, 출처가 보임 | 휴대폰 미검증 |
| 3 | 비행기 모드에서 앱 재실행 | 저장된 배경지도와 기본 경로가 보임 | 휴대폰 미검증 |
| 4 | 위치 거부 후 다시 시도 | 앱이 종료되지 않고 권한 안내 제공 | 휴대폰 미검증 |
| 5 | 위치 허용 후 GPS 기록 시작 | 현재 위치·시간·이동 기록 갱신 | 휴대폰 미검증 |
| 6 | 화면을 끄고 평지에서 이동 | 진행 알림 유지·다시 열면 기록 반영 | 휴대폰 미검증 |
| 7 | 일시 중단·종료·재실행 | 종료한 기록과 진행 중 복구 상태가 구분됨 | 휴대폰 미검증 |
| 8 | 알림 거부/허용 | 상태 안내 및 알림이 권한에 맞게 동작 | 휴대폰 미검증 |
| 9 | 본인이 확인한 GPX로 경로 이탈·복귀 | 연속 이탈 조건 후 알림·복귀 상태 갱신 | 휴대폰 미검증 |
| 10 | 30분 이상 기록·제조사 절전 | 수신 공백·배터리 사용·복구 결과 기록 | 휴대폰 미검증 |

위치와 알림은 실제 사용 동작에서 시스템 안내를 확인하세요. 제조사 절전 설정·OS 강제 종료는 기록을 중단시킬 수 있어 기기별 확인이 필요합니다. 테스트용 가상 GPX를 따라 이동하지 마세요.

추가 점검: 나의 산행 → 기록 내보내기 → 저장 위치 선택 → JSON 파일 생성. 저장 창 취소 후 다시 시도도 확인하세요. 나의 산행 → 기록 가져오기에서 이 JSON을 선택하고 추가·중복 수를 확인한 뒤 복원할 수 있습니다. 진행 중인 산행이 있으면 먼저 저장하세요. 기록별 GPX 저장도 추가 확인하세요.

연결 상태 표시를 누르면 서버 설정 여부와 오류 안내를 확인할 수 있습니다. 이번 기본 APK는 서버 주소가 비어 있어 기기 저장 모드입니다.

산행 준비 탭에서 인터넷에 연결해 예보, 기관 공지, 출처와 수신 시각을 확인하세요. 현재 코스의 개방 여부는 공지 원문에서 확인할 수 있습니다. 코스 상세의 주변 시설 탭에서는 반경과 시설 종류를 바꿔 보세요.

파일 선택 점검은 예시 GPX 가져오기와 후기 사진 첨부를 각각 확인하세요. GPX는 미리보기에서 취소하거나 확인해 저장할 수 있습니다. 후기 사진은 첨부 후 저장하고 앱을 다시 열어 표시를 확인하세요.

## 이번 APK에서 사용할 저장 방식

기기 저장 모드입니다. PC의 로컬 서버 계정·일정·후기가 휴대폰에 자동 동기화되는 버전은 아닙니다. 공개 HTTPS 서버와 앱 인증 연결이 다음 개발 항목입니다. 앱 삭제 시 기기 저장 자료가 지워지므로 예시 기록으로 점검하세요.

## 오류를 전달할 때

휴대폰 모델, Android 버전, 확인한 순서, 기대한 결과와 실제 결과를 적어주세요. 화면을 공유할 때 정확한 위치·개인 기록·비밀번호는 가려주세요.

## 개발자가 다시 빌드할 때

프로젝트 폴더에서 다음을 순서대로 실행합니다. 이 PC에 준비된 프로젝트 전용 개발 도구를 사용합니다.

```powershell
node scripts/sync-native.mjs
node scripts/build-android.mjs
node scripts/verify-android.mjs
```

검증 스크립트는 APK를 `outputs`에 복사하고 서명·앱 정보·지도 파일·SHA-256 보고서를 갱신합니다. 새 PC에서는 SDK 약관을 확인하고 개발 도구를 먼저 준비해야 합니다.
