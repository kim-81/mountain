# v0.3 지도 개발 결과 · 2026-11-05

## 구현과 확인

- 서울 초기 대상 산 8곳 주변 도로·산길·숲·하천·산봉우리 41,585개 OSM 객체를 수집하고 직접 SVG로 표시합니다.
- 아차산(서울둘레길 5), 북한산 종로(18), 관악산(11)의 OSM 관계 경로 3개를 기본 제공합니다. 기관이 검증한 GPX는 아닙니다.
- 원본 코스 번호·출처 ID·원본 기준/수정 시각·기여자·ODbL 정보를 포함합니다.
- 다른 5곳은 기본 경로 미제공 상태로 표시하며 사용자 GPX를 추가할 수 있습니다.
- 확대/축소, 전체 경로 맞춤, 마우스 드래그, 방향키 이동, GPS 수신 후 내 위치 중심 이동을 구현했습니다.
- 저장 영역 밖은 배경지도 범위 밖임을 표시합니다. 없는 자료를 새 지형이나 도로로 채우지 않습니다.
- 배경 선형 자료는 약 2m 허용오차로 단순화했고 기본 산행 경로는 단순화하지 않았습니다.
- 오프라인 자료는 약 8.7MB의 JSON과 실행용 데이터 모듈로 포함됩니다. 앱 코드·사본·브라우저 캐시를 포함한 전체 용량은 이보다 큽니다.
- 배경 타일을 외부 서버에서 받지 않으며 앱 실행 시 사용자 GPS를 OSM/Overpass로 전송하지 않습니다.

## 구분할 데이터

| 데이터 | 역할 | 표시 |
|---|---|---|
| 서울시·한양도성 안내 | 거리·예상 시간·출발/도착 등 코스 설명 | 공식 안내 수치·확인일 |
| OSM 기본 경로 | 기여자가 편집한 실제 선형 경로 후보 | OSM 기본 경로 · 현장 미검증 |
| 사용자 GPX | 사용자가 직접 가져온 경로 | 사용자 GPX · 현장 미검증 |
| GPS 기록 | 기기가 실제 수신한 좌표 | 실제 기록·현재 위치 |

공식 거리와 OSM 계산 거리는 다를 수 있으며 둘 다 상세 화면에 구분해 표시합니다. 개편 전 통합 코스라고 표시된 수락·불암산 경로를 현재 개별 코스에 연결하지 않았습니다.

## 검증

- 자동 검사 27개 통과: 기존 계정·일정·GPS 검사와 투영/역변환·카메라·영역 경계·출처·경로 데이터·네이티브 번들 검사를 포함합니다.
- 브라우저에서 확대·전체 보기·방향키 이동·마우스 드래그를 확인했습니다.
- 기본 경로가 없는 인왕산에서는 이탈 감지 선택이 비활성화되는 것을 확인했습니다.
- GPS 미수신 상태에서 ‘내 위치’를 누르면 안내 메시지를 표시합니다. 실제 사용자 위치는 검증에 수집하지 않았습니다.
- 서버를 종료하고 새로고침한 뒤 배경지도와 기본 경로가 다시 표시됨을 확인했습니다. 이때 북한산 지도에 1,524개의 SVG 경로 객체가 표시되었습니다.
- 모바일 390px, 데스크톱 1280px에서 가로 문서 넘침이 없음을 확인했습니다.
- Android APK 컴파일과 서명·리소스 검사를 완료했습니다. Android 휴대폰 설치·백그라운드 GPS·알림·배터리 및 iPhone 빌드는 아직 검증하지 않았습니다.

## Android 빌드 완료 및 다음 순서

1. 사용자가 “약관에 동의하고 빌드 진행”으로 승인했습니다. 필요한 Android SDK 약관을 수락하고 프로젝트의 `.build-tools`에 JDK 17·Android SDK·Gradle을 준비했습니다. PC의 보안 정책은 변경하지 않았습니다.
2. Android 빌드는 BUILD SUCCESSFUL로 완료됐습니다. `outputs/sangil-ttara-0.3.0-debug.apk`(7,190,379바이트)를 생성했습니다.
3. SDK 도구로 서명·앱 이름·버전·Android 8 이상 지원·지도 파일 포함을 확인했습니다. 결과는 `outputs/android-build-report.json`에 있습니다.
4. 다음은 실제 Android 휴대폰 설치 후 위치·알림 권한, 화면 꺼짐 GPS와 복구 검증입니다. [설치와 검증 안내](Android-설치와-검증.md)를 참고하세요.
5. iPhone 빌드에는 Mac/Xcode와 기기/서명이 필요합니다. 공개 HTTPS 서버·네이티브 계정 연동·실시간 정보도 남아 있습니다.

공식 SDK 약관: https://developer.android.com/studio/terms
