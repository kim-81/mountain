# 산길따라 0.4.0 · 계정 관리와 파일 저장

갱신: 2026-11-05. 휴대폰에서 테스트 중인 0.3.0 APK는 그대로 보관합니다.

## 이번 구현

| 기능 | 제공 범위 | 확인 상태 |
|---|---|---|
| Android 기록 내보내기 | 나의 산행 → 기록 내보내기 → 시스템 파일 저장 창에서 폴더 선택. 추가 저장소 전체 권한 불필요 | Kotlin 컴파일 및 웹→네이티브 메시지 검사, 실기기 저장 미검증 |
| iPhone 기록 내보내기 | 공유 창을 통해 파일 앱 등에 저장하는 소스 | Windows에서 iOS 컴파일·기기 검증 불가 |
| 비밀번호 변경 | 서버 계정의 계정 관리에서 현재·새 비밀번호 입력. 다른 세션 해제, 현재 세션 갱신 | 예시 계정 통합 검사 |
| 서버 자료 내보내기 | 본인 계정·작성 일정·후기·사진·본인 참가 응답 JSON. 타인의 비밀번호·자료 미포함 | 소유자 범위 및 인증 검사 |
| 서버 계정 탈퇴 | 현재 비밀번호와 ‘탈퇴’ 확인. 본인 일정·후기·사진·응답·세션 삭제. 기기 기록 삭제는 별도 선택 | 두 계정 간 자료 보존·외래키 삭제 검사 |
| 요청 오류 처리 | 15초 제한, 통신 단절·HTML 오류 응답·인증 만료 안내. 저장 요청을 자동 재시도하지 않음 | 응답 유형별 자동 검사 |
| HTTPS 웹 운영 준비 | 공개 원점·포트·데이터 폴더 환경 설정, Secure 쿠키, 고정 원점 CSRF 검사, SIGTERM 정상 종료 | 로컬 HTTPS 프록시 설정 모의 검사 |

서버 계정 기능은 PC 미리보기 또는 향후 같은 출처의 HTTPS 웹에서 사용합니다. **이번 Android APK도 기기 저장 모드이며 공개 서버에 연결된 버전은 아닙니다.**

## 테스트할 순서

Android는 0.3.0 점검을 계속해도 됩니다. 0.4.0으로 업데이트한 뒤에는 예시 산행 기록을 만들고 ‘기록 내보내기’를 눌러 파일 저장·취소·다시 시도 흐름을 추가 확인하세요. 이 APK는 JSON 내보내기를 제공하며 JSON 복원 기능은 아직 없습니다.

PC에서는 `미리보기.cmd` 실행 → 테스트 계정 로그인 → 나의 산행 → 계정 관리에서 내보내기·비밀번호 변경을 확인합니다. 탈퇴는 삭제해도 되는 예시 계정으로만 확인하세요. 별명을 잊거나 비밀번호를 잊은 경우의 복구 서비스는 아직 없습니다.

## 다음 의존성

1. 실제 Android 휴대폰 GPS·알림·파일 저장 피드백을 반영합니다.
2. 공개 HTTPS 주소와 운영 서버를 정한 뒤 서버를 배치하고 네이티브 앱 인증·일정·후기 연결을 구현합니다. 현재 공급자 가입·결제·외부 공개는 진행하지 않았습니다.
3. 날씨·탐방 통제·시설 데이터 공급과 갱신 정책을 정하고 실제 자료를 연결합니다.
4. iPhone 빌드에는 Mac/Xcode와 서명·테스트 기기가 필요합니다.

외부 UI·지도 라이브러리는 추가하지 않았습니다. Android 파일 선택과 iOS 공유는 OS 기본 기능을 사용합니다.
