# 산길따라 0.5.0 · 기록 보관과 오류 검증

2026-11-05. 사용자는 서울 지역에서 GPS 현장 테스트를 진행하지 못했고 다음 등산 때 피드백을 전달하기로 했습니다. 현장 GPS 검증을 기다리는 동안 개발을 진행하며, 모의 검사 결과를 실제 기기 검증으로 기록하지 않습니다.

## 추가 기능

- 나의 산행 → 기록 가져오기: JSON 파일 선택 → 기록 수·중복 수 확인 → 사용자 확인 후 추가.
- 기존 기록 번호는 건너뛰고 덮어쓰지 않습니다. 로그인한 계정 또는 현재 비회원 영역에만 추가합니다.
- 0.4.0에서 내보낸 schemaVersion 1 파일과 새 schemaVersion 2 기록 백업을 지원합니다. 서버 계정 자료 내보내기는 복원 대상이 아닙니다.
- JSON은 최대 16MB, 1,000개 기록, 전체 150,000개 GPS 지점으로 제한합니다. 산 번호·좌표·수신 시각 순서·거리·시간·완주 형식을 검증하고, 잘못된 기록이 있으면 파일 전체를 취소합니다.
- 가져오기 과정은 계정·비밀번호·서버 일정·후기를 복원하지 않습니다. 가져온 계정 식별자는 무시하고 현재 영역을 사용합니다.
- 저장 공간 부족 시 복원을 취소하고 기존 기록을 유지합니다. 진행 중인 산행이 있으면 복원을 막습니다.
- 기록별 GPX 저장: XML 문자 처리, 좌표와 시간 포함. 2분을 넘는 GPS 공백은 분리된 구간으로 저장합니다.
- 기록 삭제 전 확인 창을 제공합니다. JSON 백업과 달리 GPX는 완주 여부와 앱의 기록 정보를 완전히 복원하는 파일이 아닙니다.

`web/js/record-files.js`가 형식 검증·백업 구성·중복 병합·GPX 생성을 담당합니다. 화면 동작은 `web/js/app.js`, 휴대폰 파일 저장은 Android MainActivity 및 iOS TrailView에 있습니다. 외부 라이브러리를 추가하지 않았습니다.

## 검증 결과

- 자동 검사 37개: 기존 지도·추천·서버 권한 검사와 백업 형식·좌표·중복·현재 영역 분리·GPX 구간·파일 크기·수신 오류 검사를 포함합니다.
- 네이티브 번들에 사용자 이벤트를 전달하는 검사로 ‘확인 전 저장하지 않음’, ‘저장 공간 부족 시 기존 기록 복구’를 확인했습니다.
- 중복·과거 GPS 신호가 이탈 횟수를 늘리지 않고, 알림 간격이 유지되는지 확인했습니다. 미래/시작 전 시각과 범위 밖 위치는 기록을 바꾸지 않습니다.
- 별도 로컬 포트 4185의 예시 데이터에서 JSON 파일 선택 → 1개 추가 → 같은 파일 재선택 시 0개 추가/1개 중복 및 추가 버튼 비활성화를 확인했습니다.
- 브라우저에서 GPX 다운로드와 삭제 확인 창을 확인했습니다. 삭제 확정은 실행하지 않았습니다.
- Android 0.5.0 Kotlin 컴파일·APK 빌드 성공. 서명·버전·지도 자료 검사는 outputs/android-build-report-0.5.0.json을 참고하세요.
- 휴대폰 파일 저장·복원, 실제 GPS·화면 꺼짐·알림·배터리 및 iPhone 컴파일은 아직 미검증입니다.

화면 증거: [예시 기록 복원 화면](screenshots/v05-record-restore.png). 이는 가상 위치를 담은 기능 검사이며 실제 산행 이력이 아닙니다.

## 사용 순서

1. 진행 중인 산행을 종료하고 저장합니다.
2. 나의 산행 → 기록 내보내기로 JSON 파일을 보관합니다.
3. 다른 설치 환경의 나의 산행 → 기록 가져오기에서 해당 JSON을 선택합니다.
4. 대상 계정·추가 수·중복 수를 확인하고 추가합니다.
5. 기록별 GPX 저장으로 다른 경로 도구에서도 사용할 수 있는 파일을 만들 수 있습니다.

GPX 가져오기에는 기존 3MB·12,000개 좌표 제한이 적용됩니다. 긴 기록의 GPX가 항상 앱의 경로 가져오기 한도에 맞는 것은 아닙니다. 기기 계정·사진·일정·GPX 경로 전체의 통합 백업은 아직 지원하지 않습니다.

## 다음 개발 과제

휴대폰 현장 피드백과 별개로 공개 서버의 네이티브 인증·일정·후기 연결, 실시간 정보 연결, 기기 저장 용량 관리와 통합 백업을 진행해야 합니다. 운영 서버 가입·약관·비용은 사용자 선택 후 진행합니다. 현재 앱은 완성된 운영 서비스가 아닌 테스트 버전입니다.
