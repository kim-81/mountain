# 산길따라 0.7.0 · 코스 날씨 연결

2026-11-05. Open-Meteo의 실제 예보 API를 연결했습니다. 산행 준비 탭에서 서울 8개 산의 공개 대표 지점에 대한 현재 기온·체감온도·바람·돌풍과 3일 예보(최저/최고 기온·강수 확률)를 조회합니다. 사용자 GPS 좌표는 이 조회에 사용하지 않습니다.

## 동작과 오류 처리

- 웹/앱에 공유 서버가 연결되어 있으면 서버를 통해 조회합니다. 서버가 설정되지 않은 앱은 공개 예보 API를 직접 조회합니다. 외부 패키지는 추가하지 않았습니다.
- 산의 대표 좌표에 대한 수치 예보이며 정상 관측값이나 실시간 탐방 통제가 아닙니다. 탐방 통제는 공식 공지 링크와 미연결 상태를 유지합니다.
- 수신 시각과 예보 기준 시각을 함께 표시합니다. 기온 0도·강수 확률 0%와 미확인값을 구분합니다. 바람은 m/s로 요청하고 응답 단위를 검증합니다.
- 서버의 신선한 예보는 15분 재사용하고 같은 산의 동시 요청은 합칩니다. 기기에도 날씨 캐시를 별도로 보관합니다. 날씨 캐시 실패로 GPS 기록을 변경하지 않습니다.
- 15분이 지난 수신값 또는 오래된 예보 기준 시각은 이전 정보로 구분합니다. 6시간을 넘긴 자료는 유효한 날씨로 표시하지 않습니다. 상태는 화면을 열거나 갱신할 때 판정하며, 백그라운드 주기 갱신은 하지 않습니다.
- 제공처나 서버 오류 시 기존 수신 시각을 새 값으로 바꾸지 않습니다. 유효한 이전 자료가 있으면 갱신 실패를 함께 표시하고, 없으면 현재 값을 만들지 않습니다.
- 제공처 요청 제한 시간은 8초입니다. 실패한 요청을 무제한 자동 재시도하지 않습니다.

## 검증

- 자동 검사 **46개 통과**. 날씨 단위·좌표·미확인값·캐시·동시 요청·갱신 실패·시간 경과·API 상태 응답과 기존 지도·GPS·계정·기록 검사를 포함합니다.
- 실제 아차산 조회에서 기온·풍속·3일 예보와 유효한 시각을 받았습니다. 수신 검사 도구는 `node scripts/check-weather.mjs`입니다.
- 별도 로컬 서버의 브라우저에서 아차산 → 산행 준비 → 실제 예보 표시를 확인했습니다. 1280px 화면에서 문서 가로 넘침이 없었습니다.
- 테스트 서버 종료 후 날씨 재확인을 눌러 ‘이전 예보 · 최신 정보 재확인 필요’, 연결 오류, 기존 수신 시각 유지가 표시됨을 확인했습니다.
- Android 0.7.0 빌드 성공. APK 서명·자료 포함 결과는 outputs/android-build-report-0.7.0.json을 확인하세요.
- 실제 Android WebView의 직접 예보 조회, iPhone 컴파일·표시 및 현장 GPS는 아직 미검증입니다. 공개 공유 서버 주소도 아직 비어 있습니다.

## 파일

`web/js/weather-data.js`: 공개 요청 주소·응답 정리·단위/시간 검증.

`web/js/weather.js`: 기기 캐시·조회 상태·날씨 화면.

`server/weather.mjs`: 산 ID 검증·서버 캐시·동시 요청 합치기.

`tests/weather.test.mjs`: 제공처 실패·캐시·API 계약 검사. 실제 날씨를 고정값으로 가정하지 않습니다.

## 이용 조건과 출처

현재 개인 공유용 개발 단계에 Open-Meteo 비상업 무료 API를 사용합니다. 무료 API는 비상업 사용과 호출 한도가 적용되며, 광고·유료 운영 등 상업 전환 때 제공 조건/플랜을 다시 결정해야 합니다. 결제·가입·유료 전환은 하지 않았습니다. API 제공처의 소스 코드를 가져온 것이 아니라 공개 데이터를 조회합니다.
