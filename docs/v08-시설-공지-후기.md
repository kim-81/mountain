# 산길따라 v0.8.0

- 서울 8개 산 주변 시설 1,546곳을 추가했습니다. 분류와 반경을 선택하고 지도에서 위치를 확인할 수 있습니다. 거리 표시는 직선거리이며 영업과 개방 상태는 현장에서 확인해야 합니다. 시설 자료 출처는 OpenStreetMap입니다.
- 산행 준비 화면에 국립공원공단, 서울둘레길, 한양도성 공지를 연결했습니다. 기관 게시 시각과 앱 수신 시각을 구분하고, 공원 전체 통제 정보는 개별 코스의 개방 여부로 해석하지 않습니다.
- 후기를 페이지별로 읽고 사진을 별도로 불러오도록 변경했습니다. 서버 저장 재시도, 수정 충돌, 삭제된 사진 접근을 검사했습니다. 계정 자료는 전체 요약과 사진을 포함하는 후기별 보관 파일로 나누어 저장할 수 있습니다.
- 자동 검사 55개를 통과했습니다. 브라우저에서 북한산 시설 필터, 위치 표시와 공식 공지 표시를 확인했습니다. 브라우저 파일 선택을 통한 사진 첨부 후 저장 확인은 남아 있습니다.
- Android 테스트 APK의 빌드와 서명을 확인했습니다. v0.7.0과 동일한 앱 ID 및 디버그 서명을 사용합니다. 실기기 설치, GPS, 백그라운드 알림 및 공개 서버 동기화는 미검증입니다.
- 기본 경로는 3개입니다. 나머지 5개는 출처와 현재 코스 일치 여부를 확인할 수 있는 경로 자료가 필요합니다. 그동안 사용자 GPX를 가져올 수 있습니다.

설치 파일은 `outputs/sangil-ttara-0.8.0-debug.apk`, 검증 기록은 `outputs/android-build-report-0.8.0.json`에 있습니다.

## v0.8.1 후기 편집 안정성

- 늦게 도착한 후기 목록이나 공지 응답이 다른 창을 덮어쓰지 않도록 변경했습니다. 이전 목록 응답이 방금 저장하거나 삭제한 후기를 되돌리지 않도록 처리했습니다.
- 사진을 변환하는 동안 추가 첨부와 저장을 잠급니다.
- 격리된 로컬 서버에 브라우저를 연결해 예시 사진을 파일 입력에 전달했습니다. 로그인 후 후기 편집, 사진 변환과 미리보기, 서버 저장, 재조회 및 사진을 유지한 내용 수정을 확인했습니다. 휴대폰의 사진 선택 창과 실제 기기 저장은 별도 확인이 필요합니다.
- 설치 파일은 `outputs/sangil-ttara-0.8.1-debug.apk`, 검증 기록은 `outputs/android-build-report-0.8.1.json`에 있습니다.

## v0.8.2 GPX 미리보기

- 파일을 읽은 뒤 지도, 거리, 구간 수, 좌표 수를 확인하고 별도로 저장합니다. 산의 대표 위치에서 가장 가까운 좌표도 3km보다 멀면 안내를 표시합니다. 거리는 코스 일치 판정에 사용하지 않습니다.
- 브라우저의 가상 파일로 잘못된 좌표 차단, 두 구간 분리, 거리 안내, 취소 시 미저장, 저장 후 지도 표시를 확인했습니다. 휴대폰 파일 선택과 현장 경로 검증은 남아 있습니다.
- 설치 파일은 `outputs/sangil-ttara-0.8.2-debug.apk`, 검증 기록은 `outputs/android-build-report-0.8.2.json`에 있습니다.

## v0.8.3 코스별 공지 우선 표시

- 선택 코스 번호나 산 이름이 제목에 있는 통제·우회 공지를 최근 목록 앞에 표시합니다. 공지 날짜와 원문 링크를 유지합니다.
- 서울시 게시판 자료에서 수락산 1코스 우회 공지가 전체 순서 7번째에서 수락산 화면의 첫 번째로 이동했습니다. 1코스와 11코스 구분을 자동 검사했습니다. 제목 정렬은 현재 개방 여부를 판정하지 않습니다.
- 설치 파일은 `outputs/sangil-ttara-0.8.3-debug.apk`, 검증 기록은 `outputs/android-build-report-0.8.3.json`에 있습니다.

## v0.8.4 산행 기록 복구

- 미종료 산행을 다시 열어 ‘종료해 저장하기’를 선택하면 기기에 남은 GPS 지점을 합친 뒤 종료 화면을 엽니다. 다른 산행 세션의 응답과 중복 지점을 무시합니다.
- 위치 묶음은 저장과 화면 갱신을 한 번씩 처리합니다. 주변 산을 찾기 위한 일회성 위치는 기기의 산행 복구 파일에 추가하지 않습니다.
- 자동 검사에서 복구가 새 GPS 수집을 시작하지 않고, 남은 지점 하나가 중복 없이 합쳐지는 것을 확인했습니다. Android 실기기와 iPhone 빌드·설치 검증은 남아 있습니다.
- 설치 파일은 `outputs/sangil-ttara-0.8.4-debug.apk`, 검증 기록은 `outputs/android-build-report-0.8.4.json`에 있습니다.

### Android 15 가상 기기 확인

v0.8.4 APK를 API 35 가상 기기에 직접 설치했습니다. 별도로 빌드한 검사 패키지에서 WebView의 첫 화면과 서울 산 카드 8개를 확인했습니다. 시험용 GPS 지점 1개를 가상 기기의 복구 파일에 넣고, 앱의 Android 연결 코드가 이 지점과 요청한 세션 ID를 WebView에 전달하는 것을 확인했습니다.

추가 검사에서 앱의 GPS 산행을 시작한 뒤 가상 기기의 위치 서비스에 모의 이동 지점을 주입했습니다. 앱이 지점 2개 이상을 받고 이동 거리를 기록했습니다. 앱 화면에서 산행을 종료해 저장한 뒤 WebView를 다시 열어 이력이 남아 있는 것도 확인했습니다.

백그라운드 검사에서는 산행 중 앱을 다른 화면 뒤로 보냈습니다. 그동안 Android의 기록 파일에 위치 지점이 추가되고, 선택 경로에서 벗어난 모의 위치에 대한 이탈 알림이 Android 알림 목록에 게시됐습니다. 앱 복귀 후 백그라운드 지점이 산행에 반영되고 종료·저장 뒤에도 남는 것을 확인했습니다. 가상 기기는 화면을 잠그지 않았습니다. 실제 산행 수신 정확도, 화면 잠금·절전 동작, 실제 기기에서의 알림 표시, 파일 선택 및 iPhone 빌드는 별도 검증 대상입니다.

## v0.8.5 개발본 · 한양도성 공지 점검

한양도성 공식 게시판의 카드형 목록과 표 형식 목록에서 제목과 게시일을 읽습니다. v0.8.4 Android 가상 기기 검사에서 북한산과 수락산 공지는 표시됐지만, 인왕산은 게시판이 표 형식으로 응답할 때 비어 있었습니다. 저장해 둔 두 공식 응답에서 각각 공지 10건을 읽는 것을 확인했습니다.

v0.8.5 개발본의 자동 검사 57개와 APK 서명 검증은 통과했습니다. Android 가상 기기에서는 북한산·수락산 공지가 표시됐고, 인왕산의 공지 목록은 여전히 표시되지 않았습니다. Android 연결 코드가 한양도성 게시판에서 HTTP 200 응답과 표 형식의 제목·게시일을 받은 것까지 확인했습니다. 앱 화면에서의 목록 처리와 표시 검증이 남아 있어 설치 안내는 v0.8.4를 가리킵니다.

## 2026-11-20 재개 점검 · v0.8.5 검증 완료

전용 Android 15 가상 기기에 v0.8.5를 설치하여 서울 8곳 각각의 산행 준비 탭에서 공식 공지 링크 표시를 확인했습니다. 한양도성의 실제 표 응답을 기기에서 받아 같은 파서로 공지 10건을 읽었으며 인왕산·북악산 화면 모두 통과했습니다. 지난 11월 7일의 표시 실패는 이번 재검사에서 재현되지 않았고, 표 형식 대응이 포함된 이 APK를 현재 테스트 파일로 제공합니다. 미재현 원인을 별도의 새 코드 수정으로 단정하지 않습니다.

0.8.4에 시험 기록·즐겨찾기를 넣고 0.8.5로 업데이트한 뒤 화면에 유지되는 것을 확인했습니다. 서명 및 APK 포함 파일 16개 비교도 통과했습니다. iOS 소스의 오래된 버전 표기를 0.8.5 / 빌드 13으로 맞췄으나 Mac 빌드는 수행하지 않았습니다.

서울 코스 일괄 검사 도구와 회귀 검사를 추가했습니다. 기본 경로 3곳의 연결 오류는 없고 다른 5곳은 미확보로 남습니다. 산 8곳의 기능 전체 완료나 실제 GPS 현장 검증 완료를 뜻하지 않습니다.
