# 서울 기본 경로 보강 · 0.8.6

2026-11-20. 이번 변경은 서울 8곳 중 기본 경로를 3곳에서 **7곳**으로 늘렸습니다. 현장 검증 완료를 뜻하지 않습니다. 봉화산은 미확보입니다.

| 추가 산 | 코스 | 지도 계산 거리 | 좌표 | 출처 |
|---|---|---:|---:|---|
| 수락산 | 서울둘레길 1코스 | 6.113km | 1,130 | OSM 관계 21955834 |
| 불암산 | 서울둘레길 3코스 | 6.828km | 1,156 | OSM 관계 22020366 |
| 인왕산 | 한양도성 인왕구간 참고 경로 | 3.896km | 422 | OSM 관계 10997594 + 등록 보행로 |
| 북악산 | 한양도성 백악구간 참고 경로 | 4.941km | 463 | OSM 관계 10997594 + 등록 보행로 |

수락·불암산은 개편 전 통합 관계를 사용하지 않고 현재의 분리된 관계를 받았습니다. 불암산은 공식 안내 방향인 북쪽 출발점에서 화랑대역 방향으로 정렬했습니다. 수락산은 도봉산역에서 실제 지도 경로 A까지의 접근 구간이 별도라는 안내를 표시합니다.

인왕산·북악산은 한양도성 순성길과 OSM 등록 보행로를 조합한 참고 경로이며 공식 GPX가 아닙니다. 돈의문 터·정상·창의문과 창의문·백악마루·숙정문·와룡공원·혜화문을 기준으로 검토했습니다. 모든 결과 선분이 실제 원본 way의 인접 node인지 다시 검사했고, 연결에 추가한 way 번호를 데이터에 보관합니다. 확인되지 않은 공백을 직선으로 연결하지 않습니다. 현재 통제·탐방 시간은 출발 전에 공식 안내를 확인해야 합니다.

불암산 경로 남쪽의 기존 배경지도 공백을 발견하여 별도 영역에 도로·산길 등 1,380객체를 보강했습니다. 지도·코스·시설 연결 일괄 검사에서 현재 제공 자료의 연결 오류는 0개입니다. 8곳 경로 완료를 요구하는 검사는 봉화산 미확보 때문에 실패합니다.

## 확인 결과

- 전체 자동 검사 70개 통과: 계정·공유·후기·복원·GPS 판정·지도·자료 연결 포함.
- 원본에 없는 연결 선분, 중복 멤버, 좌표 누락, 보행/출입 제한 자료 차단 검사 추가.
- 브라우저에서 수락산·불암산 경로와 접근 안내 표시 확인.
- Android 15 가상 기기에서 추가 경로 4곳의 좌표 수·지도·출처 안내와 코스 선택/이탈 감지 준비 상태 확인. 이 검사에서는 GPS 수집을 시작하지 않았습니다.
- 0.8.6 APK 서명과 포함 자료 16개가 소스와 일치함을 확인. 실제 휴대폰 GPS·공개 HTTPS 공유·iPhone 빌드는 별도 미검증.

## 봉화산 조사 결과

서울시 공식 안내는 봉수대공원 상단에서 출발·도착하는 4.2km 순환 코스입니다. 공식 코스 자료 PDF의 안내도를 확인했습니다. 과거 두루누비 GPX는 시작점에서 들어가는 구간을 포함하고 있으며 전체를 그대로 붙이면 현재 순환 코스와 달라집니다. 이를 비교하는 과정에서 북동부의 일부 지점과 현재 OSM 등록 보행로의 차이 및 연결 부재를 확인했습니다. 기본 경로 등록을 보류했으며, 과거 GPS 좌표와 PDF 지도를 APK에 복제하지 않았습니다.
