## 중요한 범위

- 공식 안내를 확인했다는 표시는 거리·소요시간·출발/도착 등 안내 수치를 확인했다는 의미입니다. 실제 탐방로 선형 데이터나 오늘의 통제 상태를 확인했다는 의미가 아닙니다.
- 한양도성의 5단계 난이도는 앱 3단계의 ‘어려움’으로 환산했으며 화면에 환산 기준을 표시합니다.
- 도로·산길·숲 배경지도를 제공합니다. 등고선·위험 지점·실시간 통제를 제공하는 지형지도는 아닙니다.
- OSM 기본 경로는 7곳이며 현장 미검증 자료입니다. 봉화산은 사용자 GPX로 추가할 수 있습니다. 테스트용 가상 GPX는 실제 산행에 사용하면 안 됩니다.
- 로컬 서버는 127.0.0.1에서만 열립니다. 두 브라우저/계정은 같은 로컬 서버에서 동기화되지만, 다른 휴대폰과 외부 인터넷에서 접속하는 서비스는 아직 아닙니다.
- 앱에 포함된 네이티브 화면은 현재 기기 저장 모드입니다. 기기 인증 연결 소스는 추가했습니다. 사용하려면 공개 HTTPS 서버 배포·주소 설정·실기기 검증이 필요합니다.
- 이번 버전에 로그인한 사용자의 GPS 이력을 서버로 자동 업로드하지 않습니다.
