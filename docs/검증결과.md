## 미검증 / 미완료

- Android/iPhone 소스는 현재 PC에서 빌드하지 못함. JDK·Android SDK와 Mac/Xcode 환경 필요.
- 실제 사용자 위치는 브라우저 QA에서 수집하지 않음. GPS 로직은 가상 입력으로 검사함.
- 실제 휴대폰에서 화면 꺼짐·앱 전환·강제 종료·재부팅 후 기록/알림 동작과 배터리 사용량 미검증.
- 사진 선택·압축의 실제 기기 동작 미검증. 서버의 사진 형식·개수·용량 검사는 코드에 포함.
- 실제 지형지도 다운로드, 기본 탐방로 GPS 경로, 실시간 날씨·통제·시설·식당 데이터 미연결.
- 공개 HTTPS 서버와 실제 휴대폰의 서버 로그인·참가 응답 동기화 미연결.

자동 검사 통과가 실전 길 안내의 안전성과 현장 정확도를 검증했다는 뜻은 아닙니다.
