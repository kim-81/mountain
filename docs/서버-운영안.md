# 산길따라 무료·저비용 운영안

2026-11-05 공식 문서 확인 기준. 가입·결제·배포 승인은 아직 받지 않았고 진행하지 않았습니다. 금액은 USD이며 세금·환율·추가 사용량은 별도입니다.

## 제안

현재는 휴대폰 테스트와 PC 미리보기를 비용 없이 진행하고, 공유 기능을 검증할 시점에 Railway 무료 체험으로 작은 테스트 서버를 준비하는 방안을 권합니다. 무료 체험 이후 이용량을 측정하고 유료 전환을 결정합니다. 자동 유료 전환이나 결제 정보 등록은 별도로 확인합니다.

| 방안 | 예상 비용 | 적합한 용도 | 한계 |
|---|---|---|---|
| 현재 PC·설치 APK | 서비스 이용료 0 | 화면·GPS·오프라인·파일 저장 확인 | 외부 사용자 사이의 서버 공유 불가 |
| Railway 신규 무료 체험 | 30일 또는 $5 크레딧 소진까지 체험 | 지인 소수의 계정·일정·후기 공유 검증 | 계정 검증·체험 제한 있음. 계속 무료 운영을 보장하지 않음 |
| Railway Hobby | 월 최소 $5, $5를 넘는 사용량은 차액 추가 | 작게 시작하는 지속 운영 | 사진·메모리·트래픽에 따라 증가. 사용량 측정 필요 |

Railway Free는 월 $1 무료 크레딧을 제공하며 체험이 끝난 뒤 전환될 수 있습니다. 이 앱이 한 달 내내 그 한도 안에서 동작할지는 실측 전이므로 확정하지 않습니다. 공식 요금상 영구 볼륨은 GB당 월 $0.15이며 다른 자원과 함께 사용량에 포함됩니다. 작은 사진 저장 한도부터 시작하고 무료 제공 주소를 사용해 별도 도메인 구매를 미루는 구성이 적합합니다. 서비스 주소 발급과 계정별 가능 기능은 가입 단계에서 확인합니다.

Render 무료 웹 서버는 영구 디스크를 붙일 수 없고 재시작 시 로컬 파일이 보존되지 않으므로 현재 SQLite DB를 그대로 올리는 지속 운영안으로 사용하지 않습니다. 다른 무료 플랫폼의 외부 DB로 바꾸는 방법도 있으나 인증·DB 구조 변경과 외부 의존성이 추가되어 이번 단계에서는 선택하지 않았습니다.

## 승인 전에 준비된 항목

- 공개 원점·포트·데이터 저장 경로 및 컨테이너 수신 주소 설정.
- HTTPS 웹의 Secure 세션 쿠키, 허용 출처 검사, 비밀번호 변경·탈퇴·내 자료 내보내기.
- 서버 요청 제한 시간과 연결 오류 안내.

## 승인 후에도 개발해야 할 항목

실제 운영 주소를 받은 뒤 네이티브 앱의 서버 인증·일정·후기 연동을 추가해야 합니다. 서버 개설만으로 현재 APK가 자동 연결되지는 않습니다. 먼저 브라우저 계정·공유·재시작 후 자료 보존을 검증하고 앱 연결을 확인합니다. 계정 복구, 사진 저장소 확장, 운영 관리·신고, 백업 복구도 별도 과제입니다.
