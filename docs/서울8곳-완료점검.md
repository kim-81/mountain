## 이번에 추가한 검사

프로젝트 폴더에서 `node scripts/audit-seoul.mjs`를 실행합니다. `outputs/seoul-readiness.json`에 산별 오류·미완료 항목을 저장합니다. 기존 자료의 오류가 있으면 실패하며, 기본 경로 미확보는 별도로 보고합니다.

`node scripts/audit-seoul.mjs --require-all`은 기본 경로가 하나라도 없을 때 실패합니다. 현재는 **봉화산 미확보로 실패하는 것이 정상**입니다. 전국 확대 전 자료 검사 기준으로 사용하며 현장 검증을 대체하지 않습니다.

- 코스 ID와 실제 지도 경로의 연결
- 경로 좌표·거리·배경지도 범위와 시설 목록 연결
- 출처·기준 시각·라이선스·기여자 표시 존재 여부
- 분리 구간, 인접 좌표 300m 초과, 안내 거리와 계산 거리 20% 초과 차이 탐지

출처 항목이 존재한다는 검사만으로 이용 조건 검토나 현재 코스 대조가 끝나는 것은 아닙니다. 후보 경로는 [공개 자료 검토](공개-경로-자료.md)를 거쳐 추가합니다.

## 서울 단계에 함께 남은 기능 검증

실제 휴대폰에서 GPS·화면 잠금·절전·이탈 알림·재실행 복구를 확인해야 합니다. 공개 HTTPS 서버의 계정·일정·후기 공유는 서버 배포와 기기 간 검증이 남았습니다. iPhone은 Mac/Xcode 빌드·서명·설치 검증이 필요합니다. 전국 산 데이터 확장은 이 서울 단계 이후에 진행합니다.
