# 설치형 앱 검증 체크리스트

아래 항목은 이 PC에서 검증 완료되지 않았습니다. 지도·이탈 알림을 실전에 제공하기 전에 반드시 수행해야 합니다.

## Android / iPhone 공통

- [ ] 실제 기기에서 빌드·서명·설치, 오프라인 첫 실행.
- [ ] 권한 미허용 상태에서 산 검색과 수동 지역 선택이 동작.
- [ ] 주변 산 버튼을 누른 뒤에만 위치 권한을 요청.
- [ ] GPS 위치 오차가 큰 실내/계곡에서 잘못된 거리를 누적하지 않음.
- [ ] 30분 이상 화면 끄기, 다른 앱 사용, 복귀 후 GPS 누락·중복 확인.
- [ ] 종료 및 저장 후 위치 사용이 중단됨.
- [ ] 사용 중 강제 종료와 OS 종료 시 원시 기록 회수/세션 복구 설계. 현재 자동 복구 미구현.
- [ ] 비행기 모드에서 저장한 예시 개념도와 기록 기능 확인. 실제 지도 연결 후 지도 저장도 재검증.
- [ ] 후기 사진 선택·수정·삭제, 저장 공간 부족 처리.
- [ ] 한글·화면 확대·가로 화면·키보드·작은 휴대폰에서 겹침 없음.

## 남은 서버/실데이터 작업

- [ ] 실제 지도와 검증된 탐방로 연결.
- [ ] 경로 이탈·재진입, GPS 오차, 알림 반복 방지, 화면 꺼짐 알림 구현·검증.
- [ ] 두 기기에서 같은 일정 열기, 참가 응답이 합쳐지는 서버 기능 구현·검증.
- [ ] 실제 인증·본인 게시물 권한·데이터 삭제/보관 정책.
- [ ] 날씨·입산 통제 API 실패/오프라인/오래된 데이터 표시.
- [ ] 출처·사진·지도 및 경로의 저장/재배포 권한 확인.
