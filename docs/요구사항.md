# 확정 요구사항

현재 반영 상태는 [개발현황](개발현황.md)을 기준으로 확인하세요. 아래 내용은 제품 요구사항의 기록입니다.


- 서울의 산 5~10곳으로 시작. 현재 데이터는 북한산·인왕산·아차산·관악산·북악산·봉화산·불암산·수락산 8곳.
- GPS 주변 산 → 맞춤 추천/검색 → 코스 선택 → 일정 생성·공유. 혼자 이용할 때 일정 생략 가능.
- 추천: 등산 경험, 체력, 산행 시간, 이동 수단, 즐겨찾기, 이전 산행/완주 이력.
- Android와 iOS 설치형 앱. 공통 화면 + Kotlin/Swift 기본 위치 기능.
- 로그인 없이 검색·추천 가능, 일정 생성/참가·기록/후기 관리는 예시 계정 필요.
- 오프라인 지도, 현재 위치, 이탈 알림은 **제품 필수 요구사항으로 유지**. 현재 초기 구현은 예시 개념도 저장과 실제 GPS 기록까지이며 실제 지도/이탈 알림의 완료를 의미하지 않음.
- 코스·교통·주차·편의시설·날씨·통제·식당/카페는 화면 구조에 포함. 검증된 실데이터 연결 필요.
- 기록: 사용자가 시작/종료, GPS 경로·거리·시간 기록, 종료 시 완주 직접 확인.
- 날짜·시간·만나는 장소를 링크로 공유. 참가·불참과 참가자 목록. 현재 응답은 기기 내 저장이며 서버 동기화 필요.
- 산행 후기·사진 등록·수정·삭제, 즐겨찾기·이력 기반 추천은 첫 개발 포함.
- 큰 글씨·버튼·사진 카드, 크림색·초록색·흙색 계열. 첨부 이미지는 디자인 참고만.
- 전국 확대, 날짜 투표, 모임 채팅은 추후 추가.

## 실제 서비스로 완성할 다음 순서

1. 서울 대표 코스의 실제 선형 경로와 출처·갱신일·이용권한 확보.
2. 허용된 오프라인 배경지도 연결, 실제 경로 위 현재 위치 표시.
3. GPS 정확도와 코스까지의 거리를 반영한 이탈 판정·백그라운드 알림 구현.
4. 실제 인증과 서버 저장, 일정 링크 도메인·앱 링크, 참가 응답 동기화.
5. 교통·시설·식당 정보 검증, 날씨·관리기관 통제 정보와 갱신 시각 연결.
6. 두 플랫폼 빌드·실기기 검증, 기록 복구·배터리·권한 거절 대응을 완성한 뒤 배포 준비.
